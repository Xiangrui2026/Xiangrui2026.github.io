THE POINTER ATLAS

一张图谱，读懂指针语法。

从声明中的名字出发：先看括号，再看后缀 [] / ()，最后看 *。每条语法都有对应的内存实验。

int *p[3];

p 是数组 → 有 3 个元素 → 每个元素是 int 指针。

≠
int (*p)[3];

p 是指针 → 指向一个含 3 个 int 的完整数组。

声明小陷阱：int *p, q; 只让 p 成为指针，q 仍然是 int。* 属于每个声明符。
函数参数：void f(int a[10]); 的 a 调整为 int *；函数内 sizeof(a) 得到指针大小，长度需要另外传入。
打印地址：printf("%p", (void *)p); 适用于对象指针；%p 的文本形式由实现决定。函数指针没有通用的 %p 可移植打印方式。
A MODEL YOU CAN TRUST

看清模型，也看清边界。

这里展示的是受控的逐步教学模型。它把 C 语义转为可观察的状态，不编译或执行任意 C 程序。

01 / REPRESENTATION

明确的表示约定

模型使用 8 位字节、4 字节 int、8 字节对象指针与函数指针、8 字节 size_t / ptrdiff_t、1 字节字符和 bool，以及小端序。模拟函数地址只表示符号，不伪造机器指令。

C 标准并不保证这些大小、指针表示、字节序或全零空指针。NULL 在本模型显示为全零；这是模型约定。

02 / ADDRESS SPACE

让地址帮助你理解

栈从 0x1000、静态区从 0x4000、堆从 0x8000、代码符号区从 0xC000 开始。对象按模型中的自然对齐分配，数组元素连续。

真实实现的局部对象顺序、地址、结构体填充以及 malloc / realloc 行为可能不同。成功、失败和搬迁路径在各示例中明确选择。静态对象和函数符号在第一次相关步骤引入视图，这并不表示它们的存储期在该语句才开始。

03 / LIFETIME

失效，不等于被清零

?? 表示未初始化或不确定的字节。free 或作用域结束后，对象标为失效，保留的字节只作历史回看，不能继续读取。指向结束生命周期对象的指针值变为不确定；原地址仅作历史标签。

free 不会自动把指针置 NULL，也不保证物理字节被擦除。只有显式赋值 p = NULL 才会改写 p。

04 / SAFETY

停止展示不保证的结果

到达未定义行为时，演示在违规操作前停止。它不会替 C 标准指定“崩溃”“乱码”或某个输出。类型约束违规单独标为需要编译诊断，不能当成正常运行。
